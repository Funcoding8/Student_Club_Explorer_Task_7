Partner: None

The Robotics Members button uses an event handler registered with
robotics.setOnAction(event -> { ... }). Clicking the button runs that handler.
members.stream() creates a stream of the original members. filter() keeps
only members whose interest equals Robotics, ignoring capitalization.
toList() collects those matches into an unmodifiable List<Member>.
The original ArrayList remains unchanged. displayMembers(matches) uses a
loop to build one line of details per member, and resultArea.setText()
replaces the previous output with the new results.

The project also includes Show All, case-insensitive name search, Names Only,
blank-search alerts, a no-match message, and the optional First Year button.
